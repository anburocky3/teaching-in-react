### Challenges

1. The Polished UI (Tailwind & Theme)

**Requirement:** Use the ThemeContext to toggle between a "Dark" mode and a "Clean-Light" mode.

**Goal:** Ensure all your portfolio is working even in persistent mode.

2. Safety App (Context & Routing)

**Requirement:** Create an AuthContext in a separate file to avoid the "Fast Refresh" error.

**Goal:** If a user is not logged in, they should be automatically redirected from /dashboard back to / using the <Navigate /> component.
